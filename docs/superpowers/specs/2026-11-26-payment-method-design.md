# จ่ายด้วยอะไร + ยอดบัตรเครดิตที่ยังไม่ได้โอน

วันที่: 2026-11-26
สถานะ: design (อนุมัติแล้ว 2026-11-26)

## ปัญหา

Mark จ่ายค่าอาหารและของใช้ผ่านบัตรเครดิต แล้วโอนเงินเข้าบัญชีอีกบัญชีไว้จ่ายบิล บางยอดโอนทันทีตอนรูด บางยอดรวบโอนตอนนั่งทำรายจ่ายกลางคืนหรือเช้า ส่วน MRT ค่าผ่อน และบิลต่างๆ โอนทีเดียวสิ้นเดือน บางรอบเงินในบัญชีนั้นจึงไม่พอจ่ายบิล เพราะมียอดหลุดและแอปไม่ได้บอกว่าอะไรยังไม่ได้โอน

## เป้าหมาย

1. เห็นว่ายอดรูดบัตรเท่าไหร่ยังไม่ได้โอน แยก "ต้องโอนเลย" กับ "รอสิ้นเดือน"
2. เก็บวิธีจ่าย (บัตรเครดิต / เงินสด / โอนจ่าย) และกรองหาย้อนหลังได้
3. จดรายการปกติโดย**ไม่ต้องกดเพิ่ม** ถ้ากรอกเยอะขึ้นจนไม่อยากจด ถือว่า feature นี้ล้มเหลว

## ไม่ทำในรอบนี้

- ระบบเตือนให้จดค่าผ่อน/บิลรายเดือน (ทำแยกรอบถัดไปถ้าต้องการ)
- รอบตัดบัตร วันครบกำหนด และการเทียบกับยอดบิลจริง
- โอนบางส่วน หรือโอนเป็นเลขกลมๆ แล้วยกยอด
- เติมวิธีจ่ายให้รายการเก่าอัตโนมัติ
- เปลี่ยนวิธีคิดงบ, `myShare`, "จ่ายจริง" และยอดคนค้าง
- ปุ่มในแอปไม่ได้โอนเงินจริง แค่บันทึกว่าโอนแล้ว

## ข้อจำกัดที่ยอมรับ

- การ์ดนับเฉพาะรายการที่จดในแอป บิลที่ตัดบัตรเองแล้วไม่ได้จดจะไม่ถูกนับ
- แก้ยอดรายการที่โอนแล้ว สถานะยังเป็น "โอนแล้ว" ต้องโอนส่วนต่างเอง
- ยอดค้างที่เกิดก่อนมี feature นี้ไม่ขึ้นเอง ถ้าอยากให้นับ ให้แก้รายการเก่าเป็น "ต้องโอน" ทีละรายการ

## ทางเลือกที่พิจารณา

| ทาง | ได้ | เสีย |
|---|---|---|
| **A. ติ๊กสถานะรายรายการ (เลือกอันนี้)** | รู้ว่ารายการไหนหลุด ใช้ได้ทั้งโอนทันทีและรวบโอน | โอนบางส่วนไม่ได้ |
| B. จดเงินโอนเป็นก้อน (ยอดรูด − ยอดโอน) | โอนเท่าไหร่ก็ได้ | ไม่รู้ว่ารายการไหนหลุด ต้องจดการโอนแยก และต้องสร้าง tab ใหม่ |
| C. มีแค่ type ดูยอดรวม | งานน้อยสุด | ยังต้องจำเองว่าโอนอะไรไปแล้ว จึงไม่แก้ปัญหา |

## ข้อมูล

เพิ่ม 2 column ใน tab `expenses` ต่อจาก H (`payee`):

| Column | ชื่อ | ค่า |
|---|---|---|
| I | `pay` | `card_due` (ต้องโอน) · `card_later` (สิ้นเดือน) · `card_paid` (โอนแล้ว) · `card_later_paid` (โอนแล้ว ที่มาจากกองสิ้นเดือน หน้าจอแสดงเหมือน `card_paid`) · `cash` (เงินสด) · `bank` (โอนจ่าย) · ว่าง = ไม่ระบุ |
| J | `paidAt` | `YYYY-MM-DD` วันที่บันทึกว่าโอนแล้ว มีค่าเฉพาะ `card_paid` และ `card_later_paid` (ข้อความด้านล่างที่พูดถึง `card_paid` ใช้กับทั้งสองค่า) |

- รายการเก่าว่างทั้ง 2 ช่อง ไม่นับเป็นยอดค้าง ค่าที่อ่านไม่รู้จักถือว่าว่าง
- `paidAt` ใช้วันที่จากเครื่องผู้ใช้ ห้ามคิดจากเวลา server เพราะ server เป็น UTC ถ้ากดก่อน 7 โมงเช้าจะได้วันก่อนหน้า
- เลือก "โอนแล้ว" จากหน้าเพิ่ม หรือเปลี่ยนเป็น "โอนแล้ว" ในหน้าแก้ไข ให้ `paidAt` = วันนี้ (ไม่ใช่วันที่ของรายการ) เพราะบางทีมาจดตอนเช้าของอีกวัน เปลี่ยนเป็นค่าอื่นให้ล้าง `paidAt`
- การแก้รายการ: ถ้า request ไม่ส่ง `pay` มา (แท็บเก่าค้าง) ต้องคงค่าเดิม แบบเดียวกับที่ `payee` ทำอยู่ ถ้ายังเป็น `card_paid` ต้องคง `paidAt` เดิม
- code เก่าอ่านแค่ A:H และเขียนตอนแก้แค่ A:G จึงไม่ลบ I/J ถ้า preview กับ production ใช้ Sheet เดียวกันก็ไม่ทำให้ production พัง

## การเลือกค่าให้อัตโนมัติ (หน้าเพิ่ม)

1. หารายการล่าสุด (ตามวันที่ แล้วตาม `createdAt`) ที่ชื่อตรงกันทุกตัวหลังตัดช่องว่างหัวท้าย และมี `pay`
2. เจอ → ใช้ค่านั้น ยกเว้น `card_paid` ให้ใช้ `card_due` และ `card_later_paid` ให้ใช้ `card_later`
3. ไม่เจอ → `bank` (เปลี่ยนจาก `card_due` หลังลอง preview 2026-11-26 เพราะโอนจ่ายบ่อยกว่า)

"โอนแล้ว" ไม่ถูกจำ เพราะถ้าเลือกให้เอง ยอดที่ยังไม่ได้โอนจะหายจากการ์ด

`card_later_paid` (เพิ่มหลังรีวิว 2026-11-26): ถ้าไม่เก็บที่มา การกด "โอนแล้ว" ของกองสิ้นเดือนจะทำให้ MRT กลายเป็น "ต้องโอน" ทุกเดือน ค่านี้เกิดเมื่อกดปุ่มของกองสิ้นเดือน หรือเลือก "โอนแล้ว" บนรายการที่เป็น/จำไว้ว่าเป็นสิ้นเดือน

- ถ้าผู้ใช้กดเลือกเองแล้ว การพิมพ์ชื่อต่อจะไม่ทับค่า จนกว่าจะบันทึกหรือกด chip รายการประจำ
- chip "รายการประจำ" และการคัดลอกรายการ (`?from=`) ใช้กฎเดียวกัน
- บันทึกแล้วค่ากลับเป็น `bank`

## หน้าจอ

### หน้าเพิ่ม
ช่อง "จ่ายด้วย" อยู่ใต้ช่อง "รายการ" เพราะค่าที่เลือกให้ขึ้นกับชื่อ เลือกได้ค่าเดียวจาก 2 กลุ่มที่วางข้างกัน:
- แบบอื่น: `เงินสด` `โอนจ่าย`
- บัตรเครดิต: `ต้องโอน` `โอนแล้ว` `สิ้นเดือน`

ปุ่มสูง 44px ไม่ล้นจอที่กว้าง 360px ถ้าค่าที่จำได้ต่างจากค่าเริ่มต้น (`โอนจ่าย`) มีข้อความ "เลือกให้ตามครั้งก่อนของ …"

### หน้าแก้ไข
ใช้ช่องเดียวกัน แสดงค่าที่เก็บไว้ รายการเก่าไม่มีปุ่มไหนถูกเลือก ถ้าบันทึกโดยไม่เลือกก็ยังว่าง ถ้าเป็น `โอนแล้ว` ให้แสดงวันที่โอน และถ้าแก้ยอด ให้เตือนว่าต้องโอนส่วนต่างเอง

### หน้าแรก: การ์ดบัตรเครดิต
- อยู่ใต้การ์ดงบ ซ่อนเมื่อไม่มียอดค้าง และไม่แสดงก่อนข้อมูลโหลดเสร็จ
- หัวการ์ด: "บัตรเครดิต · ยังไม่ได้โอน" + ยอดรวม 2 กอง
- กองละแถว: ยอด, ชื่อกอง, จำนวนรายการ, ปุ่ม "โอนแล้ว" กดที่ยอดเพื่อกางดูรายการ กองที่ว่างปุ่มกดไม่ได้
- **นับทุกรอบ** ไม่รีเซ็ตตามรอบเงินเดือน
- ยอดของแต่ละรายการ = ยอดที่รูดจริง คือ `cashOut` (ยอด − ส่วนที่คนอื่นออกให้) ไม่ใช่ `myShare`
- ปุ่มเปลี่ยนเฉพาะรายการที่แสดงอยู่ตอนกด (ส่ง id ไป) เป็น `card_paid` พร้อม `paidAt`
- ระหว่างบันทึกกดซ้ำไม่ได้ ถ้าบันทึกไม่สำเร็จ ให้แสดงข้อความและยอดยังเท่าเดิม
- สำเร็จแล้วมีแถบ "บันทึกว่าโอนแล้ว ฿X · ยกเลิก" 8 วินาที กดยกเลิกแล้วแต่ละรายการกลับเป็นสถานะเดิม หลังแถบหายแล้ว แก้ได้ที่หน้าแก้ไข

### หน้ารายการ
- chip กรอง เลือกได้ค่าเดียว: `ทั้งหมด` `บัตรเครดิต` `เงินสด` `โอนจ่าย` ใช้ร่วมกับตัวกรองเดิมได้
- "บัตรเครดิต" รวมทั้ง 3 สถานะ รายการที่ไม่ระบุแสดงเฉพาะใน "ทั้งหมด"
- ถือเป็นตัวกรอง: ปิดสีหัววันและ % เทียบรอบก่อน และต่อท้ายในป้ายขอบเขตของการ์ดสรุป
- แต่ละแถวที่ระบุวิธีจ่ายมีข้อความเล็กใต้ชื่อ เช่น "บัตร · ต้องโอน"

### นำเข้าสลิป
ทุกรายการบันทึกเป็น `bank` เพราะสลิปคือหลักฐานการโอนจ่าย ไม่เพิ่มช่องในหน้าตรวจสลิป ถ้าผิดให้แก้ในหน้าแก้ไข

## API

เพิ่ม endpoint สำหรับเปลี่ยนสถานะหลายรายการในครั้งเดียว ใช้ทั้งปุ่ม "โอนแล้ว" และ "ยกเลิก"
- รับรายการของ `{id, pay, paidAt}` โดย `pay` ต้องเป็นค่าบัตร และค่าที่โอนแล้วต้องมี `paidAt`
- เขียน Sheet ใน request เดียว (batch) จะได้ไม่สำเร็จแค่ครึ่งเดียว
- ถ้าหา id ไม่เจอแม้แต่ตัวเดียว ไม่เขียนอะไรเลย ตอบ error ให้โหลดข้อมูลใหม่
- อยู่หลัง auth เดิมของ `proxy.ts`
