## ต้องรู้

- **งบไม่ยกไปรอบถัดไป** ทุกวันเงินออก การ์ดงบกลับเป็น "ตั้งงบรอบนี้ →" ต้องกรอกใหม่ เหมือนเดิมที่ต้องตั้งทุกเดือน แค่จังหวะเปลี่ยนจากวันที่ 1 เป็นวันเงินออก
- **งบของรอบ = แถวของเดือนถัดจากเดือนที่รอบเริ่ม** รอบ 29 ก.ย. – 28 ต.ค. ใช้แถว `2026-10` รอบ 29 ต.ค. – 26 พ.ย. ใช้ `2026-11`
- **ข้อความ "วันหยุดมีผลเฉพาะช่วง 27–29" ไม่จริงเสมอ** ก.พ. 2570 เงินออกวันที่ 26 ถ้าวันนั้นเป็นวันหยุดก็เลื่อนอีก โค้ดคำนวณถูก แต่ข้อความใน README, comment ใน `lib/holidays.ts` และ spec ยังเขียนแคบไป วันหยุดในสัปดาห์สุดท้ายก่อนวันที่ 29 มีผลได้ทั้งหมด
- **ปี 2571 ต้องเติมรายการวันหยุดเอง** ใน `lib/holidays.ts` เมื่อ ธปท. ประกาศ หน้าหลักจะเตือนตั้งแต่ 29 ธ.ค. 2570 วิธีเติมอยู่ใน README หัวข้อ "รอบเงินเดือน"
- **วันหยุดพิเศษที่ประกาศกลางปี** ต้องเติมเองเหมือนกัน ไม่งั้นรอบเดือนนั้นคลาด 1–2 วัน

## การตัดสินใจที่ทำแทนไป (Rulings)

แต่ละข้อบอกว่าตัดสินอะไร และถ้าตัดสินผิดจะเสียอะไร

1. **Lint** — แผนคาดว่า `eslint` ทั้ง repo เงียบ แต่มี 2 error เดิมบน `master` ใน `components/ui/DateField.tsx:152` และ `components/ui/ThemeToggle.tsx:10` (`react-hooks/set-state-in-effect`) ไม่ได้แตะเพราะนอกขอบเขต ไฟล์ที่ branch นี้แก้ lint สะอาด — ถ้าผิด: error ค้างบน `master` ต่อไป (build ไม่กระทบ)
2. **ข้อที่แก้ ตรวจด้วย script ใน browser ไม่ใช่ test ในชุด** — โปรเจกต์ไม่มี test harness ของหน้าเว็บ — ถ้าผิด: ถ้าพังซ้ำทีหลัง `npm test` จะไม่จับ

ข้อที่ reviewer ไม่ตัดสิน ตัดสินว่า "คงไว้" ทั้งหมด:

3. กราฟสัปดาห์ไฮไลต์ "วันนี้" ตั้งแต่ตอน build — ของเดิม และ spec ห้ามแตะกราฟ — เสี่ยง: ไฮไลต์ผิดแวบเดียวตอนเปิด
4. ข้อมูลไม่โหลดใหม่ถ้าเปิดค้างนาน — ของเดิม — เสี่ยง: รายการเก่าจนกว่าจะ reload
5. ไม่มีปุ่ม "รอบถัดไป" และปุ่มไม่มีสถานะ active — spec กำหนด 2 ปุ่ม — เสี่ยง: ต้องกด "รอบนี้" หรือแก้ช่องวันที่เอง
6. หน้ารายการไม่เตือนปีที่ไม่มีรายการวันหยุด (ย้อนไปก่อนปี 2569) — spec ให้เตือนที่หน้าหลัก — เสี่ยง: รอบเก่าคำนวณจากเสาร์–อาทิตย์โดยไม่บอก
7. Reviewer ไม่ได้เทียบวันหยุดกับประกาศ ธปท. จริง — เทียบ 2 แหล่งต่อปีตอนออกแบบแล้ว — เสี่ยง: วันเงินออกคลาด 1 วันถ้าแหล่งผิด
8. "ใช้ได้วันละ ฿0" ทั้งที่ "เหลือ ฿10" — ปัดลงตามจริง — เสี่ยง: ดูแปลก
9. โหลดรายจ่ายไม่สำเร็จ → ไม่โชว์ช่วงรอบและนับถอยหลัง — ตาม spec
10. หน้ารายการ "ถึงวันที่" ว่าง แต่ยอดหน้าหลักตัดที่วันจบรอบ — ตาม spec — เสี่ยง: รายการที่ลงวันที่ล่วงหน้าเกินวันเงินออกถัดไป โผล่ในหน้ารายการแต่ไม่อยู่ในยอดหน้าหลัก
11. งบไม่ยกไปรอบใหม่ — ดีไซน์เดิม (ดูหัวข้อ "ต้องรู้")
12. `formatDateShort` อ่านวันที่แบบ UTC แล้วแสดงแบบเวลาท้องถิ่น — ของเดิม ผู้ใช้อยู่ UTC+7 — เสี่ยง: คลาด 1 วันถ้าใช้ในโซนเวลาตะวันตกของ UTC
13. วันที่ในชีตที่พิมพ์มือแบบไม่เติม 0 (`2026-10-6`) จะหลุดจากยอดรอบ — แอปเขียนแบบเติม 0 เสมอ — เสี่ยง: แถวที่แก้มือแบบนั้นไม่ถูกนับในหน้าหลัก
14. พิมพ์ปี พ.ศ. ในช่องวันที่แล้วปุ่มรอบคำนวณตามปีนั้น — ของเดิม
15. "จากวันที่" ที่พิมพ์เองช้ากว่า "ถึงวันที่" → รายการว่าง — ของเดิม
16. README บรรทัด 36 เรียก tab ว่า "งบรายเดือน" — ยังจริงตาม key ของแถว
