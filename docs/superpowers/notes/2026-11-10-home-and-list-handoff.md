## อยู่บน master แล้ว (หน้าแรก)

- **Hero card** (`components/home/HomeHero.tsx`) แทนการ์ดวันนี้/รอบนี้/งบ: "เหลือรอบนี้" ตัวใหญ่ + แถบ + "ใช้ไป" (มี "จ่ายจริง" เป็นบรรทัดล่างเมื่อต่างกัน) + แถว วันนี้ / ใช้ได้วันละ / เฉลี่ยจริง + บรรทัดคาดการณ์
- **สีเลข "เหลือรอบนี้"** ตามสัดส่วนงบที่ใช้: เขียว <70%, เหลือง 70-85%, ส้ม ≥85%, แดงเมื่อเกิน (`remainingLevel` ใน `lib/pace.ts`) Mark บอกว่าจะลองใช้จริงก่อนค่อยปรับ
- **เลขวันนี้** ขาว → เหลือง (≤125% ของแผน) → ส้ม (≤150%) → แดง แผน = `(เหลือ + ที่ใช้วันนี้) ÷ วันที่เหลือ` ปัดลง (`todayPace`)
- **ปฏิทินรอบเงินเดือน** (`CycleCalendar`) เริ่มวันอาทิตย์ ลงสีรายวันด้วยบันไดเดียวกัน มีคอลัมน์รวมรายสัปดาห์เทียบเพดาน
- **แตะวันที่มียอดในปฏิทิน** → `/expenses?date=YYYY-MM-DD` (หน้ารายการอ่านจาก `window.location.search` ไม่ใช้ `useSearchParams` เพราะหน้านี้ static)
- `lib/forecast.ts` คาดการณ์เงินหมด (ซ่อน 2 วันแรกของรอบ) + `dailyAverage`
- `lib/cash.ts` `cashSpent` = เงินที่ออกกระเป๋าจริง หักที่เขาคืนในรอบ
- chip + ปุ่มสลับธีมมีพื้นที่แตะล่องหนราว 44px (utility `hit-area` ใน `globals.css`)
- หัวหน้ารายการเปลี่ยนเป็น "รายการจ่าย"

## หน้ารายการ (merge แล้ว)

1. การ์ดสรุปยุบเหลือบรรทัดเดียว แตะเพื่อกาง (`PeriodSummary`)
2. หัววันลงสีด้วยบันไดเดียวกับหน้าแรก วัดจาก myShare เทียบแผนของวันนั้น (`lib/dayPace.ts`) ลงสีเฉพาะตอนไม่มีตัวกรอง หัววันเขียน "ของฉัน ฿X" ทุกวัน (มีส่วนที่ออกให้คนอื่นจะเป็น "฿ยอดรวม · ของฉัน ฿X") ไม่มีคำว่า "เกิน" แล้ว Mark ขอตัดออก ระดับบอกด้วยสีอย่างเดียว
3. แถวหมวดโชว์ % เทียบรอบก่อนแบบวันเท่าวัน (`lib/categoryTrend.ts`) ซ่อนเมื่อ <10% และไม่แสดงถ้าช่วงวันที่ไม่ใช่รอบเงินเดือนหรือมีค้นหา
4. ตัวกรอง "ค้างอยู่" + จุดเล็กๆ บนแถว (`lib/outstanding.ts`) **ข้อจำกัด:** ยอดค้างเก็บรายคน ไม่ใช่รายรายการ จึงบอกไม่ได้ว่าการคืนเงินล้างรายการไหน ทุกรายการของคนที่ยังมียอดค้างจะติดจุด
5. สลับเรียง "ตามวัน | ยอดมาก" (`ExpenseRow` แยกออกมาใช้ซ้ำ)

## ควรเช็คบนเว็บจริง (production)

ยังไม่เคยลองกับ Google Sheet จริง (ผมไม่มี credential ในเครื่อง ใช้ข้อมูลปลอมใน Playwright) หลังขึ้น production ให้เช็ค:

1. หน้าแรกโหลดรายการ/งบได้ ปฏิทินขึ้น เพิ่มรายการได้ ล็อกอิน/ออกได้ (ยังไม่เคยลองกับ Sheet จริงหลังอัปเกรด Next)
2. หน้ารายการ: สรุปยุบ กางแล้วเห็น % เทียบรอบก่อน หัววันลงสีตามที่คาด รอบที่ไม่เคยตั้งงบไม่มีสี
3. ชิป "ค้างอยู่" กรองถูก จุดเขียว/ส้มตรงความหมาย (เขียว = เขาค้างเรา, ส้ม = เราค้างเขา) และ "ยอดมาก" เรียงถูก
